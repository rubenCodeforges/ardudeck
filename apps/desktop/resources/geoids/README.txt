egm96-15.pgm
  EGM96 geoid undulations, 15 arc-minute grid in GeographicLib PGM layout, the same file ArduDeck Locus ships.
  Used to turn WGS84 ellipsoid heights (3D Tiles, CESIUM_RTC glTF) into EGM96 heights above mean sea level.
  Source: GeographicLib geoid data (https://geographiclib.sourceforge.io/C++/doc/geoid.html), public domain.
